# 📱 Filtro-Chiamate-Auto-Spam

**Filtro-Chiamate-Auto-Spam** è un'app Android progettata per proteggere gli utenti da chiamate indesiderate, truffe telefoniche e abusi. Sviluppata in Python e ottimizzata per l'Italia, offre un sistema di whitelist e regole intelligenti per filtrare i numeri sospetti.

---

## 🚀 Funzionalità

- 🔒 Blocco automatico delle chiamate da numeri non autorizzati  
- ✅ Whitelist personalizzabile: solo i contatti approvati possono chiamare  
- 🇮🇹 Regole italiane per identificare prefissi e pattern di spam  
- 📴 Funzionamento offline: nessuna connessione internet richiesta  
- 🧠 Algoritmo leggero e veloce, compatibile con dispositivi Android 7.0+

## 💡 Come funziona

L'app analizza le chiamate in entrata e le confronta con:
- La whitelist dell’utente  
- Un set di regole italiane predefinite  
- Eventuali numeri segnalati manualmente

Se il numero non è autorizzato, la chiamata viene bloccata o silenziata.
